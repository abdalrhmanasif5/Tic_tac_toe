1. **Choose your mode:** Decide whether you want to play against the computer or with a friend.  
2. **Take turns:** Players alternate placing their marks (X or O) until one player gets three in a row horizontally, vertically, or diagonally.  
3. **Win or draw:** If a player wins, the game will announce it. If all squares are filled without a winner, the game is a draw.
